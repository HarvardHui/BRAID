# BRAID

Repository for BRAID (Batch-effect Reconciliation and Anomaly-aware Imputation for Data), used for evaluating missing value imputation (MVI) under both batch-free and batch-affected scenarios.

BRAID is a modular framework - users can apply their preferred methods within the framework to better suit their analysis pipelines.

The main goal of BRAID is to inform MVI method developers and evaluators about batch effect influence on their findings.
